# Основания решений

Исходники сверены для `c6b7691`. Нативные записи и численные замеры запланированы на этап 0. Выводы ниже относятся к коду.

| Наблюдение | Решение для первого варианта | Что могло бы его изменить |
|---|---|---|
| В beta.2 изменены `src/workers/layoutEngine.ts`, появился `src/workers/towForce.ts`. Эталон владельца установлен в Raincoat и по манифесту соответствует beta.1. | Два независимых сравнения. Движение проверять с Raincoat, стоимость визуальных изменений измерять также против выбранного исходного commit. | Видимое расхождение на одинаковом жесте требует согласования базы до правок. |
| В `src/render/EdgeMesh.ts` ребро уже представлено четырьмя вершинами в общем меше. Сейчас `updatePositions` перезаписывает весь позиционный буфер. `GraphRenderer.redrawHoverLinks` и `redrawPath` чертят свои прямые. | Расширить существующий буфер. Для кривых переиспользовать квадратичную траекторию в основном слое и подсветке, включая направление стрелки. Прямой путь оставляет прежнюю стоимость геометрии. | Дополнительные сегменты, обновление диапазонов GPU и ограничения на сверхплотных сценах выбирать по измерениям. |
| `GraphRenderer.cullAndLabel` уже отсекает невидимое, проверяет часть коллизий и ограничивает создание `Text` четырьмя экземплярами за обычный проход. В 3D обычные кандидаты сортируются по глубине. Для ряда приоритетных подписей пересечение не проверяется. | Сначала объединить порядок и экранное размещение. Отделить пересчёт кандидатов от текущей прозрачности. Сохранить штатные режимы PNG, паузы и повторного открытия. | При доказанной стоимости растрирования испытать атлас и возврат к `Text` для неподдержанных символов. |
| `GraphView.recomputeVisual` объединяет поисковые совпадения с подсветкой чипов, оверлеев и фокуса. `drawClusterHulls` получает сообщества. `NodeFacts.folder` обычно содержит путь родителя. | Передать явные результаты поиска отдельно. Группировать папки по ключу пути. Сообщества и выбор раскладки использовать в прежнем значении. | Условия видимости, цвет и подпись сверять в сцене, где одна папка входит в два сообщества. |
| `normalizePanel` дополняет старую панель глобальными значениями. `getState` основной вкладки сериализует камеру и запрос, у локального графа нет собственного сохранения вида. | В момент создания явно передавать новое оформление, при чтении без маркера воспроизводить старое. Сохранить только визуальную часть у листа. | Смена всего глобального `DEFAULT_3D_PANEL` меняет старые частичные состояния. Полное копирование панели в каждый лист затрагивает физику и управление раскладкой. |
| В стенде `bench/bench.ts` камера по умолчанию 3D, worker по умолчанию 2D, drag callbacks пусты, а `layout.stop()` стоит перед движением камеры. | Добавить явные пары камера/worker и проверять, что действие действительно изменило позицию, камеру или выбранный узел. Применять один вариант стенда к обеим сборкам. | Старый отчёт 0.10.1 о 10k и результат CPU-микротеста полезны для истории. Для вывода о новом 3D-графе нужны свежие парные прогоны. |

## Референсы

- **Orrery 1.0.7.** Один `LineSegments` на слой рёбер, стабильная контрольная точка и шесть сегментов. Обновление только связей перетаскиваемого узла рассчитано на остановленную раскладку. При нашем движении соседей это оставило бы часть линий на прежних координатах. [Рендер Orrery](https://github.com/c-miles/orrery/blob/dc30dcf6e201e7bc6da0c67995ac89621f6ffdb9/src/orrery/render.ts) · [MIT](https://github.com/c-miles/orrery/blob/dc30dcf6e201e7bc6da0c67995ac89621f6ffdb9/LICENSE)
- **New 3D Graph 2.8.3.** Затухание начинается до границы видимости. При заполнении атласа цикл упаковки останавливается и для оставшихся имён используется запасная ячейка. Переносим поведение по расстоянию. Результат должен сохранять точное имя любой выбранной заметки. [Рендер подписей](https://github.com/Apoo711/obsidian-3d-graph/blob/ef1aca3f1fd31b53e9c279697ad27e8078853fcb/src/rendering/label-renderer.ts) · [MIT](https://github.com/Apoo711/obsidian-3d-graph/blob/ef1aca3f1fd31b53e9c279697ad27e8078853fcb/LICENSE)
- **Stellar Graph 3D 1.3.0.** Восемь хабов выбираются по степени. Папки обозначаются облаками, которые растворяются при приближении. Контекст наведения и поиска влияет на видимость текста. [Код групп и подписей](https://github.com/thor040175/stellar-graph-3d/blob/371162ffc75694a31c1ee261716a9e89a2a548b8/src/main.ts) · [MIT](https://github.com/thor040175/stellar-graph-3d/blob/371162ffc75694a31c1ee261716a9e89a2a548b8/LICENSE)
- В документации PixiJS 8.19.0 указано, что отсутствующие в bitmap-шрифте символы пропускаются. На этапе сравнения проверить строки с произвольным Unicode. [Документация PixiJS 8.19.0](https://github.com/pixijs/pixijs/blob/v8.19.0/src/scene/__docs__/text/bitmap.md)
