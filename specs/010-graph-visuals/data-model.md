# Состояние вида и данные кадра

## Где хранить оформление

Уже существуют `GraphInsightSettings.panel`, `ViewPreset.panel` и `GraphViewState` версии 1 для камеры и запроса. `LocalGraphView` сохраняет глобально глубину и 3D. Предлагаемое расширение - необязательный версионированный визуальный блок в состоянии глобального и локального листа и визуальных настройках, проходящих через пресеты и профили. Он хранит вариант оформления, каналы размера/цвета/свечения, палитру, стиль узлов, `nodeScale`, параметры подписей, рёбер и папок. Режим камеры и видимость соответствующих слоёв должны воспроизводиться после открытия настроенного вида. Текущие глобальные и локальные настройки сохранять совместимыми. Поля физики, координаты и пины остаются в существующих владельцах данных.

| Вход | Как инициализировать вид |
|---|---|
| Штатная команда создаёт leaf для глобального или локального графа | Передать в `setViewState` явный начальный визуальный блок для нового графа. Применить новые визуальные значения только к этому виду. |
| Команда повторно показывает уже открытый leaf | Использовать его текущее состояние. |
| Восстановление старого workspace, в том числе пустого состояния старой локальной вкладки | При наличии старой установки и отсутствии маркера взять визуальные поля прежней общей панели, заполнить отсутствующие поля прежними defaults и выбрать прежние правила отрисовки. |
| Восстановление вида после обновления, дублирование или перенос в другое окно | Копировать сохранённый визуальный блок и сохранить камеру/запрос по действующему протоколу. При неполном или повреждённом блоке нормализовать известные значения, сохранить исправные части. |
| Применение старого пресета или профиля | Нормализовать его панель по прежним defaults. Для нового формата применять сохранённую версию. Сохранить идентификаторы и определения встроенных и пользовательских пресетов. |
| Новая установка без прежних данных | При создании графа использовать новые визуальные значения. Для частичного старого `data.json` предусмотреть отдельную фикстуру. По одному отсутствующему полю внешнего вида нельзя определить новую установку. |

Исходные значения прежней версии должны быть зафиксированы отдельно от defaults новых графов. Читать эффективную визуальную часть через один путь в `GraphView`, `LocalGraphView`, панели, легенде и при экспорте. Изменение оформления и применение пресета обновляют текущий лист и его сериализацию. При импорте глобального профиля сохранить штатную семантику явного применения профиля и проверить следующие открытия. Чтение и нормализация старых данных не перезаписывают другую вкладку. Проверить последовательности `setState` до/после инициализации рендера и сохранение прямо перед закрытием. Порядок версии встроенных пресетов менять только при реальном изменении их набора.

## Данные, вычисляемые в памяти

| Данные | Время жизни и пересчёт |
|---|---|
| Идентичность узла и ребра | Использовать `GraphNode.path` с учётом существующей идентичности отсутствующих ссылок. Числовые ID действуют внутри одной модели. Изгиб пары сохраняет сторону после переиндексации. Встречные направленные рёбра различимы. При смене модели сбросить старые индексы и анимации. |
| Важность и контекст | Основная оценка - `inCount + outCount` по модели. Сначала исключить скрытые узлы из кандидатов. Равенство разрешать по стабильному пути. Пересчитывать очередь при изменении модели, фильтра или метрики. Hover, выбор, явные совпадения, маршрут и Explore меняют приоритет без перестроения графа. |
| Папка | Ключ - полный путь непосредственного родителя или его первый компонент. Для корня предусмотреть явное правило без огромного облака. Для ручной палитры хранить соответствие ключа валидному цвету. Ключи одинаково названных вложенных папок остаются различимы. Положение и радиус вычислять из доступных участников, спроецированных текущей камерой. |
| Кандидат подписи | Стабильный ключ заметки или папки, текст, якорь, приоритет, размеры в экранных CSS-пикселях. Кэш размеров зависит от текста, шрифта и темы. Размещение и прозрачность текущего кадра отделены от настроек и никогда не записываются в vault. |
| Переход | Хранить целевую и текущую прозрачность, состояние порога и последнее место подписи. Настройки ограничиваются допустимым диапазоном, числовые значения конечны. Переходы заканчиваются при достижении цели, скрытые вкладки используют текущий механизм паузы. |

Кэш размеров, список затухающего текста, индексы рёбер и текстуры принадлежат конкретному renderer. Освобождать их при пересборке модели, смене темы в части тематических ресурсов и закрытии вида.
