# UI and export contracts

All attachments adds isolated files; linked attachments remain in the default graph. Missing targets are source-qualified and open source notes unless now resolved. No binary Markdown reads. Missing targets have no fabricated creation date and do not enter date history/timeline. Note-oriented overlays apply to notes.
JSON preserves real paths and adds kind/unresolved metadata only on extended nodes. GEXF uses dense numeric IDs. Markdown uses full attachment paths and plain missing-target labels with source links, never internal virtual IDs. Snapshot comparison is limited to matching membership scope.
