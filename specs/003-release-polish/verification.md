## Дополнительная приёмка перед выпуском, 2026-10-20

По прямому запросу владельца публикация 0.10.1 разрешена после закрытия оставшихся проверок.

Редактирование связей в настоящем Obsidian: созданы три изолированные тестовые заметки A, B, C. Граф показал A -> B. После vault.modify с заменой на A -> C старая связь исчезла, новая появилась без ручной перезагрузки. Затем заметка открыта в split-панели и изменена через настоящий editor.setValue; тот же экземпляр открытого графа отразил удаление A -> B и сохранение A -> C. Тестовые заметки перемещены в корзину vault. Пользовательские заметки не редактировались.

JSON и GEXF скачаны через штатные методы экспорта в приватный временный каталог. JSON разобран, GEXF проверен XML-парсером. В обоих файлах 5510 узлов и 11552 ребра, все концы рёбер ссылаются на существующие узлы; новая связь A -> C присутствует в JSON. Файлы с данными пользователя не включены в репозиторий.

Нативная проверка PNG обнаружила oversized capture: extract без frame использовал огромные offscreen bounds и падал с Invalid typed array length. Исправление и финальная повторная проверка описаны ниже.

10k: расширенный CUA IAB прогон PASS. 10000 узлов, 29956 рёбер; первый worker frame 149.1 мс, стабилизация 10.958 с. Active layout 59.88 FPS, pan 58.82 FPS, zoom 59.88 FPS. Ошибок и кадров >33 мс нет. Это синтетический 2D стенд, не измерение любого vault. Полная методика: benchmark-10k.md.

Финальная проверка PNG: исправленная сборка установлена с полным backup прежнего каталога плагина. Штатный экспорт скачал PNG 1946 x 2318 при viewport 973 x 1159. Файл открыт и визуально осмотрен: граф присутствует, захват ограничен viewport. PNG exception больше не воспроизводится, console error после экспорта пуст. В общем журнале есть отдельная ошибка индексирования чужой заметки, появившаяся до установки исправления; отсутствие всех ошибок хоста не заявляется. Настройки плагина сохранили прежний SHA-256.
