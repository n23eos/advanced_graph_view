# План доводки 0.10.1

Цель: законченный интерфейс и устранение подтверждённых дефектов без расширения набора режимов.
Дата и источник: запрос владельца и локальный аудит, 2026-10-20.

Структура: TypeScript, PixiJS 8.19, Obsidian API 1.13.1, воркеры, Vitest. Spec Kit уже подключён. Исходное дерево 81008c7 чистое.

Решения:
- TimelineBar согласованно обновляет ползунок и фильтр, останавливает устаревшее проигрывание.
- Persistence валидирует записи, сохраняя совместимость исправных данных.
- Размещение панелей зависит от их фактических размеров. Иконки и фокус следуют текущей теме.
- Новые UI-сценарии проверяются на воспроизводимом браузерном стенде с реальным renderer.
- WebGL имеет явный fallback в карточку ошибки; отсутствующий GPU не переключает приложение на несовместимый CanvasRenderer.
- Воркеры, renderer и асинхронные ответы учитывают закрытие и повторное открытие view.
- Пустое хранилище возвращает пустые метрики без запуска PageRank.

Этап: реализация, браузерная проверка и финальные verify/build завершены; 712 тестов PASS.
Baseline: npm run verify PASS, 683 теста, 77 файлов, 12 прежних lint warnings.
Проверки: регрессии, verify, build, браузерные сценарии, независимое ревью, diff. Детали в verification.md.
Ограничение: native apps в CUA недоступны; нативная визуальная приёмка остаётся отдельной.
Следующий шаг: нативная приёмка тестового vault по release-readiness.md, затем отдельно разрешённый выпуск.

Продолжение 2026-10-20 завершено: по прямому запросу владельца 0.10.1 установлена с полным backup прежней версии. Проверены runtime-хеши, настройки на диске и в памяти, рабочие данные, reload, disable/enable, команды и регистрация view в Obsidian 1.13.7. Повторные verify/build PASS, 712 тестов. Нативное окно через CUA недоступно, поэтому визуальная приёмка остаётся открытой. Детали в verification.md.
