# Feature Specification: доводка перед релизом

**Feature Branch**: `codex/release-polish`

**Created**: 2026-10-20

**Status**: Implemented and locally verified; native acceptance pending

**Input**: Запрос владельца: улучшить внешний вид, устранить шероховатости и повысить стабильность перед новым выпуском.

## User Scenarios & Testing

### User Story 1 - Предсказуемый временной фильтр (Priority: P1)

Пользователь перемещает ползунок, переключает дату создания/изменения и обновляет граф. Показанный месяц всегда соответствует видимым заметкам.

**Independent Test**: включить фильтр, сменить режим даты, запустить и остановить проигрывание.

**Acceptance Scenarios**:

1. При смене дат ползунок возвращается к последнему месяцу и граф показывает все даты.
2. Запуск проигрывания с конца сразу показывает первый месяц. После смены дат прежнее проигрывание останавливается.
3. При пустом наборе дат проигрывание недоступно.

### User Story 2 - Сохранённая раскладка не ломает граф (Priority: P1)

Повреждение отдельных сохранённых координат не мешает открытию графа. Корректные позиции и закрепления сохраняются.

**Independent Test**: открыть граф с частично повреждёнными позициями, затем с корректным старым файлом.

**Acceptance Scenarios**:

1. Некорректные координаты пропускаются, остальные восстанавливаются.
2. Старые корректные двухмерные позиции остаются совместимыми.

### User Story 3 - Аккуратное управление в разных панелях (Priority: P2)

Пользователь видит граф, поиск и выбранный режим без наложения панелей. Кнопки имеют согласованный вид и работают с клавиатуры.

**Independent Test**: поиск с длинным фильтром, сворачивание панели, таймлайн и восстановление вида при ширинах 1200, 700 и 360 px.

**Acceptance Scenarios**:

1. Панель настроек располагается ниже фактической высоты поиска и строки фокуса.
2. Таймлайн помещается в узкую вкладку и не перекрывает нижние инструменты.
3. Заголовок настроек доступен через Tab, Enter и Space; состояние сворачивания объявлено.
4. Поиск без активного состояния не оставляет пустую строку; ошибка заметна и связана с полем ввода.

### Edge Cases

- Пустой граф, один месяц, длинные пути и фильтры, светлая тема.
- Смена режима во время проигрывания и закрытие вкладки с активным таймером.
- Повреждённые координаты, отсутствующие заметки, сохранённые позиции прежних версий.

## Requirements

### Functional Requirements

- **FR-001**: Временной фильтр, подпись и ползунок изменяются согласованно.
- **FR-002**: Повреждённые сохранённые позиции не передаются в граф.
- **FR-003**: Управление остаётся доступным в контейнере шириной 360 px.
- **FR-004**: Основные элементы управления соответствуют теме Obsidian и доступны с клавиатуры.
- **FR-005**: Подготовлены описание изменений и проверяемые файлы кандидата релиза.
- **FR-006**: Сбой фонового расчёта даёт возможность перезапуска; смена периода в панели изменений не показывает результат прежнего периода.
- **FR-007**: При недоступном WebGL оба вида графа показывают объяснение и повторную попытку, освобождая ресурсы неудачного запуска.
- **FR-008**: Пустое хранилище открывается без ошибки расчёта; кнопка сброса поиска принимает клики.
- **FR-009**: Закрытие одного графа не освобождает общие графические ресурсы другого открытого вида.

### Key Entities

- Временной фильтр: выбранный месяц, режим даты, состояние проигрывания.
- Сохранённая позиция: путь заметки, координаты, признак закрепления.

## Success Criteria

### Measurable Outcomes

- **SC-001**: Во всех проверенных сценариях временного фильтра месяц совпадает с результатом.
- **SC-002**: Частично повреждённый файл не препятствует восстановлению исправных позиций.
- **SC-003**: На ширинах 1200, 700 и 360 px проверенные панели не перекрывают основные действия.
- **SC-004**: Новый пользователь может найти поле поиска, очистить фильтр и свернуть настройки с клавиатуры.

## Assumptions

- Готовится локальный кандидат 0.10.1; публикация и установка в личный vault не входят в этот проход.
- Сохраняются существующие настройки, стек и режимы. Новые режимы графа не добавляются.
- Браузерный стенд использует синтетические заметки и адаптер хоста. Он не заменяет нативную приёмку в Obsidian.
