# План

Цель: выбор центра Explore поиском и кликом по узлу.

Текущая структура: GraphInsightView управляет режимом и NavigationTrail; ExploreSession.travelTo уже поддерживает произвольный переход. GraphRenderer выполняет hit-test и направленную навигацию. Обновление сохраняет существующий стек.

Решения: окно FuzzySuggestModal API Obsidian 1.13.1; полные пути результатов; проверка актуального пути и hiddenMask перед переходом. Панель доступна после отцепления. Узел под мышью имеет приоритет перед armed link. Наведение не вооружает несвязанный узел для автоперехода.

Этапы: спецификация -> окно и интеграция -> regression tests -> браузерная проверка -> независимое ревью -> build и установка Raincoat.

Проверки: npm run verify, npm run build, UI в доступном Chrome; контроль SHA-256 и неизменности настроек после установки.

Ограничение: native Obsidian недоступен через CUA. Нативный fuzzy search и камера в Raincoat требуют визуальной проверки владельцем.
