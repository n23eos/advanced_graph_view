# Проверка улучшений runtime

Дата: 2026-10-02. Проект: `/Users/nickeo23/code_projects/plugins/obsidian/advanced_graph_view`.

## Выполнено

- Нулевой радиус столкновений больше не запускает построение и обход дерева. Делегирование initialize сохраняет размерность и порядок сил, положительный радиус работает при переключении и повторной инициализации.
- `reheat` и `cluster` не запускают выключенную физику. Группировка сохраняется до включения.
- Сравнение моделей учитывает концы рёбер, веса и счётчики узлов, включая неразрешённые ссылки.
- Изменение заметок повторно индексирует активный content-фильтр даже при неизменной топологии. События объединяются debounce. Отменённый scan не публикует старые данные, освобождает статус индексации; закрытие view отменяет scan.
- MetricsClient отбрасывает результат старой модели, когда уже ожидает новая.
- Бенчмарк поддерживает одинаковую alpha=0.3 и проверяет выдачу одного tick на вызов. Браузерному стенду возвращён необходимый DOM-адаптер.
- Spec Kit 1.0.5 подключён для дальнейших изменений; текущая структура зафиксирована, старый код сохранён.

## Браузер и ограничения

`node bench/build.mjs`, локальный сервер только на 127.0.0.1, Chrome через cua_repl. Реальные GraphRenderer и LayoutClient отрисовали 10000 узлов и 29956 рёбер, первый кадр через 127 мс после init. Просмотрен экран, выполнены штатные scripted pan/zoom.
Стенд: pan 49.8 FPS, zoom 42.9 FPS, p95 кадра 70.0/71.2 мс. Его exploratory-цель 50 FPS не достигнута, verdict FAIL. Во время замера физика уже остановлена; это ограничение рендера, не доказательство регрессии раскладки. Сопоставимого браузерного baseline нет.
В DOM нет ERROR после исправления адаптера. Console errors относятся к установленному браузерному расширению MetaMask, источник chrome-extension; ошибок плагина в просмотренном журнале нет.
Нативный Obsidian через доступный CUA недоступен. Реальный vault, фильтр после редактирования заметки в Obsidian и разные размеры панелей живьём не проверены. Настройки, CSS и пользовательские данные не изменялись. На момент исходной проверки установка в хранилище и публикация не выполнялись. Установка по следующему запросу владельца описана ниже.
