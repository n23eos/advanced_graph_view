# Улучшение производительности и надёжности runtime

Дата: 2026-10-02. Запрос владельца: причесать, улучшить и оптимизировать плагин.

## Текущая структура

Это существующий плагин Graph Insight 0.9.0. `src/view` связывает представления и настройки, `src/render` отвечает за PixiJS, `src/data` за индекс хранилища, `src/workers` за раскладку и анализ. Проверки: ESLint, TypeScript и Vitest; production-сборка через esbuild. Исходная проверка: 644 теста проходят, 12 существующих lint warnings, ошибок нет. Git изначально чистый.

## Требования

1. При нулевом радиусе столкновений симуляция не строит дерево столкновений. При положительном радиусе сохраняет разделение узлов и порядок сил в 2D и 3D. Изменение радиуса и повторная инициализация продолжают работать.
2. При отключённой физике команды `reheat` и `cluster` не запускают симуляцию. Новая группировка сохраняется и применяется после включения. Перетаскивание вручную продолжает работать.
3. Каждый измеряемый вызов бенчмарка раскладки исполняет настоящий tick. Замеры до и после используют одинаковые данные и температуру, без остывания до пустого вызова.
4. MetricsClient не публикует результат старой модели, если в очереди уже ожидает новая. Обновление связей и их весов обнаруживается даже при неизменном числе узлов и рёбер; перестановка записей кеша сама по себе не перезапускает раскладку. Активный content-фильтр повторно индексируется после изменения заметок.

## Готовность

Пройдены регрессионные тесты, `npm run verify`, production build и diff check. Есть сопоставимые локальные замеры. Ограничения живой проверки Obsidian указаны честно. Настройки и протокол сообщений сохраняют совместимость.

## Границы

Без новых режимов, обновления зависимостей, большого рефакторинга, смены дизайна, установки в хранилище и публикации релиза.
