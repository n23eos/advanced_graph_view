# Graph Insight: принципы разработки

Версия 1.0.0, дата 2026-10-02. Источник: инструкции владельца и текущий код.

- Существующий плагин Obsidian сохраняет стек TypeScript, PixiJS, d3-force-3d и воркеры. Spec Kit применяется к новым изменениям, без переписывания накопленного кода.
- Чистая логика и протоколы проверяются Vitest. Для исправлений нужны содержательные регрессионные проверки.
- Оптимизация требует подтверждённой лишней работы и сопоставимых замеров. Не менять точность, внешний вид или настройки ради цифр.
- Сохранять пользовательские данные, настройки и чужие изменения. Каталоги `!notes` остаются приватными и игнорируются Git через `\!notes/`.
- Обязательные проверки: `npm run verify`, `npm run build`, просмотр diff. Для затронутого UI дополнительно проверять живой сценарий доступными средствами.
- Публикация, push и установка в пользовательское хранилище требуют соответствующего разрешения. Этот этап ограничен локальным кодом и проверками.
- В создаваемом тексте использовать обычный дефис, без U+2013 и U+2014.
